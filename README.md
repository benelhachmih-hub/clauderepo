# clauderepo

A repository for projects and experiments built with Claude Code.

## Getting started

Clone the repository:

```bash
git clone https://github.com/benelhachmih-hub/clauderepo.git
cd clauderepo
```

## Contents

This repository is just getting started. Files and projects will be listed here as they are added.

## Contributing

1. Create a branch: `git checkout -b my-change`
2. Commit your changes: `git commit -m "Describe the change"`
3. Push the branch: `git push -u origin my-change`
4. Open a pull request on GitHub.
